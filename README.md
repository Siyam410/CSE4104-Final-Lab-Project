# Basketball Shooting Game

A simple 2D Basketball Shooting Game developed using **Python and PyOpenGL** as a Computer Graphics project.

The game allows players to shoot a basketball into a hoop using either mouse controls or keyboard controls.

## Features

- 2D basketball shooting gameplay
- Mouse-based shooting using click, drag, and release
- Keyboard-based aiming and shooting
- Adjustable shooting angle and power
- Short trajectory preview while aiming
- Basketball with glow and shading effects
- Basket with backboard, rim, and net
- HIT and MISS result display
- Automatic game reset after 3 seconds

## Technologies Used

- Python
- PyOpenGL
- OpenGL
- GLUT

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/Siyam410/CSE4104-Final-Lab-Project.git
```

**2. Open the project folder**

```bash
cd your-repository
```

**3. Install the required libraries**

```bash
pip install PyOpenGL PyOpenGL_accelerate
```

**4. Run the game**

```bash
python main.py
```

Make sure GLUT/FreeGLUT is installed and available on your system.

## Controls

| Key / Action | Function |
|---|---|
| Mouse Drag | Aim and shoot |
| W | Increase power |
| S | Decrease power |
| A | Decrease angle |
| D | Increase angle |
| SPACE | Shoot |
| R | Reset game |
| ESC | Exit game |

## Gameplay

Drag the basketball backward using the mouse and release it to shoot. You can also adjust the shooting power and angle using the keyboard.

The game displays **HIT!** or **MISS!** depending on the shot result and automatically resets after 3 seconds.

This project demonstrates basic computer graphics concepts, including:
